# 更新日志 Release Notes

## 版本号规则

`1.{年份后两位}.{月份}.{当月序号}`

- 当月发布的第一个版本序号为 `0`，之后每发布一次加 `1`；进入新的月份后重新从 `0` 开始。
- 例：2026 年 11 月第一个版本是 `1.26.11.0`，第二个是 `1.26.11.1`；2026 年 12 月第一个版本是 `1.26.12.0`。
- 版本号只写在根目录的 `VERSION` 文件里，`pyproject.toml`、后端接口 `/api/version` 和网页底部都从这里读取。
- 发布新版本：运行 `.venv\Scripts\python.exe src\bump_version.py`，它会按上面的规则算出下一个版本号、写入 `VERSION`，并在本文件顶部插入新版本的标题，然后补充更新内容即可。

## 1.26.11.2 — 2026-11-21

### 新增
- **主题切换按钮**（页头右上角）：在 自动 → 浅色 → 深色 之间切换，选择保存在当前浏览器里。"自动"会在按钮上显示浏览器报告的系统模式，例如"自动（浅色）"。有些手机浏览器不会把系统夜间模式告诉网页，可以用它手动切到深色。手动选择后页面一打开就是对应颜色，不会先闪一下浅色；原生控件和地址栏颜色也会跟着变。

### 修复
- **手机刷新后仍在使用旧的 JS / CSS**：部分手机浏览器会无视 `Cache-Control: no-cache`，刷新时只重新请求网页，`app.js`、`style.css` 直接用缓存里的旧文件。结果就是新功能不生效，比如新加的按钮点了没反应。现在网页引用这两个文件时会自动带上内容指纹（`app.js?v=…`），文件一改地址就变，浏览器必须重新下载。以后更新网页不再需要清手机缓存。

### 升级
- 改了 `src/main.py`，**需要重启服务（或服务器）**。数据库和配置不变。
- 升级后第一次打开时，如果按钮仍然没反应，清一次手机浏览器缓存即可。此后每次更新刷新页面就行。

## 1.26.11.1 — 2026-11-21

### 新增
- **深色模式**：跟随手机 / 电脑系统的夜间模式自动切换，切换时页面实时变化，不需要刷新。日期选择器、下拉框等原生控件和手机浏览器地址栏也会一起变色。所有颜色集中定义在 `style.css` 开头（浅色、深色各一套）。

### 修复
- **手机上下滑动有时划不动、整个页面连页头一起被拖动**：去掉了 `html` / `body` 上的 `overflow-x: hidden`。在手机浏览器（尤其 iOS Safari）上，它会产生两层滚动区域，导致滑动时有时滚的是外层页面。现在改为只在内容区用 `overflow-x: clip` 裁掉横向溢出，不会产生新的滚动区域。
- **快速连点按钮时页面被意外放大**：关掉了双击放大（`touch-action: manipulation`），双指缩放和正常滚动不受影响。同时防止手机横竖屏切换时字号自动变大。

### 升级
- 只改了网页文件（`src/static/`）和版本号，**数据库和配置不变**。
- 更新 `VERSION` 后需要重启服务（或服务器），网页底部和 `/api/version` 才会显示新版本号；只看网页效果的话，手机上刷新页面即可。

## 1.26.11.0 — 2026-11-21

首个版本。

### 我的冰箱
- 记录食材的名称、数量、种类、存入日期、保质期和备注，可以编辑、删除。
- 列表主要显示存入日期和已存天数；快过期（3 天内）标橙、已过期标红，这两种才显示到期日期。
- 排序：已过期和快过期的排最前，其余按存入日期从早到晚排。
- 保质期可以不填（"不设保质期"），这类食材永远不会被判为过期。
- 数量从下拉中选：缺货、见底、1份～10份、很多。
- 每个食材有四个按钮：编辑、见底、吃完（自动加入补货清单）、删除。
- 名称输入框带下拉列表：列出食谱库用到的所有食材，输入文字即可筛选（比如输入"牛"列出所有带"牛"的食材）。
- "常用"预设按钮（包菜、茄子、白菜、蘑菇、豆角、豆芽菜），一键填好种类、数量和保质期。
- 支持搜索、按种类筛选、按状态筛选。

### 推荐食谱
- 用冰箱里没过期的食材匹配食谱的主料，按"缺得少 → 能用掉临期食材 → 匹配率高"排序。
- 今日一荤一素：分别推荐一道荤菜和一道素菜，可以"换一换"，并列出还需要买的食材，一键加入补货清单。
- 可以选择最多缺 0/1/2 种食材，或者不限（显示全部食谱）。
- 可以按 全部 / 荤菜 / 素菜 筛选。

### 食谱库
- 每道菜分荤/素：可以手动选，也可以按主料自动判断（关键字和例外词在 `config.json` 里配置）。
- 从链接导入食谱：自动识别菜名、用时、食材（含用量）和步骤，在编辑页把每个食材设为主料/调料/删除后保存；目前只允许 `https://pullit.up.railway.app`。
- 已有食谱可以重新编辑：菜名、用时、荤素、食材、用量、步骤都能改。
- 食谱详情显示用量和原菜谱链接。

### 补货清单
- 数量选"缺货"、点"吃完"、或在补货清单页直接添加，都会进入补货清单；缺货不需要保质期，也不在食材页显示。
- "快用完了"列出数量为"见底"的食材，可一键加入清单。
- "买到了"跳到食材页并预填好表单；往冰箱添加同名食材后，清单里的这一项会被自动删除。
- 标签上用红色角标显示待买数量。

### 安装与部署
- `setup_venv.bat`（项目根目录）：一键新建虚拟环境 `venv_{版本}_{日期时间}` 并安装全部依赖。
- `python -m server`（`src/server.py`）：前台运行服务器；不依赖启动目录，没有控制台也能运行，Ctrl+C 正常关闭。
- `python -m service`（`src/service.py`）：用 pywin32 把服务器包装成 Windows 服务（只负责服务的启动和停止，注册由用户手动完成）。服务器在子进程中运行。停止或系统关机时先优雅关闭，超时再结束整个进程树。服务器意外退出时报告服务失败。`python -m service debug` 可以在控制台按服务方式测试。
- 版本号保存在 `VERSION` 文件，网页底部显示当前版本，新增 `/api/version` 接口；`src/bump_version.py` 按规则生成下一个版本号。

### 其他
- 适配手机：窄屏下表格变卡片，表单和弹窗适配触摸操作。
- 日志写入 `logs/fridgemanager.log`，按天轮转，自动清理 14 天前的日志。
- 所有配置集中在 `config/config.json`：端口、数据库路径、日志、食材预设、荤素关键字、导入规则等。
- 数据库为 SQLite；旧数据库启动时会自动升级表结构。
